# Additional Workflow Categories

**Remaining workflow categories**

---

## PERF Workflow (Performance)

```bash
/siftcoder:perf analyze src/services/
```

Commands:
- `/perf analyze` - Static performance analysis
- `/perf profile` - Runtime profiling guidance
- `/perf benchmark` - Create benchmarks
- `/perf bundle` - Analyze bundle size

---

## MIGRATE Workflow (Migration)

Commands:
- `/migrate upgrade` - Upgrade dependencies
- `/migrate framework` - Framework migration
- `/migrate database` - Database migrations
- `/migrate breaking` - Breaking changes

---

## MONITOR Workflow (Production Insights)

Commands:
- `/monitor logs` - Log pattern analysis
- `/monitor errors` - Cluster production errors
- `/monitor alerts` - Alert fatigue analysis
- `/monitor health` - System health assessment

---

## COMPLY Workflow (Compliance)

Commands:
- `/comply licenses` - License compatibility
- `/comply sbom` - Software Bill of Materials
- `/comply gdpr` - GDPR compliance
- `/comply standards` - Coding standards

---

## INTEGRATE Workflow (External Services)

Commands:
- `/integrate github` - GitHub integration
- `/integrate issues` - Issue tracker sync
- `/integrate slack` - Slack notifications
- `/integrate ci` - CI/CD setup

---

## COST & EFFICIENCY

Commands:
- `/budget` - View token usage
- `/budget set` - Set token budget
- `/budget optimize` - Optimization suggestions
