# Quickstart

Three pages. Read in order, total time about ten minutes.

1. [First five minutes](first-five-minutes.md) — install, start the daemon, capture your first event, see it come back via search.
2. [Verifying the install](verifying.md) — the things that should be true once you're set up. If they aren't, the page tells you which knob to turn.
3. [When to reach for SiftCoder](when-to-use.md) — honest about what it does well and what it doesn't. Read this before you adopt it project-wide.

If you only have time for one page, read [First five minutes](first-five-minutes.md). The rest can wait.
