# /siftcoder:ideate

Brainstorm features for the current project. Memory-grounded — won't re-suggest rejected ideas.

Invokes the `ideate` skill. Topic argument optional; if omitted, scans the repo and offers ideas across the whole project.

Output is two portfolios (Safe / Asymmetric) plus one Dark Horse, with file/feature citations and impact/risk for each.

See `skills/ux/ideate/SKILL.md` for rules.
